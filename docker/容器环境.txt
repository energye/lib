
环境准备：
1. 安装好环境依赖的 docker image 镜像
2. lazarus, fpc编译工具和fpc源码
	lazarus-3.6-0.tar.gz
	fpc-3.2.2.source.tar.gz
	fpc-3.2.2.x86_64-linux.tar
	fpc-3.2.2.i386-linux.tar
	fpc-3.2.2.aarch64-linux.tar
	fpc-3.2.2.arm-linux.tar

运行docker
1. 导入安装好环境依赖的 docker image 
2. 运行不同系统架构 docker image
3. 运行脚本编译 lazarus


运行准备好的docker环境， 并构建Lazarus

Debian 11 ====================================================================================
arm32:
docker run -d -it \
  -v /home/yanghy/app/docker/workspace:/app \
  -v /home/yanghy/app/gopath/src/github.com/energye/workspace/lib:/app/lib \
  --name debian11_arm debianarm32_11_base:1
docker exec -it debian11_arm /bin/bash
